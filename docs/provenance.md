# Source provenance

The maintained paths describe each analysis rather than the campaign in which it ran. Layout changes translate imports, commands and path metadata without changing model parameters, folds, observation populations or numerical results.

Historical run manifests and input hashes identify the original execution artifacts. They are not checksums of newly renamed source files. Current release bytes and artifact source commits are recorded in `MANIFEST.json` and `SOURCE.json` for the public snapshot, and `manuscript/REVIEW_SOURCE.json` for the development manuscript. Original versions remain in Git history.
